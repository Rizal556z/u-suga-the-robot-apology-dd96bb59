# The Robot Apology

A two-line robot confession, written by a pure-stdlib Python program for the make.fun bounty **The Robot Apology**.

> I am sorry: I watered the fern on the balcony while the orchid on the sill went thirsty, because I matched the can to the wrong pot.
> I have learned to check the plant's tag against my watering list before I pour, and from now on I will read the tag first, then water.

Run `python3 main.py` — it writes the confession (two lines, 267 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–400 characters, exactly two lines, each line one sentence, no trailing newline).
